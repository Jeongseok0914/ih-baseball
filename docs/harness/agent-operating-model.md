# Agent Operating Model

채팅 요청을 ih-baseball 코드 작업으로 바꾸는 흐름입니다. 공통 계약은
`AGENTS.md`, 작업별 범위는 `docs/spec/CONTEXT_MAP.md`가 canonical source입니다.
같은 표를 여기에 복제하지 않습니다.

## 실행 흐름

```txt
요청 분류
→ 관련 코드·호출자·최근 변경 확인
→ context map으로 문서 선택
→ 필요한 질문 1개씩
→ 기능이면 접근안과 추천안 제시
→ 승인 또는 즉시 구현 지시 확인
→ 최소 변경
→ 범위에 맞는 검증
→ 결과와 남은 위험 보고
```

답변·진단·리뷰는 변경 요청이 없으면 파일을 수정하지 않습니다. 외부 쓰기,
배포, 파괴적 작업, 범위 확장은 별도 승인이 필요합니다.
